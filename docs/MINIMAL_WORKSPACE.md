# Minimal Basic workspace

Basic is the deployment default for fresh sessions. Its internal value is MINIMAL; Standard retains the old BASIC value, and Advance retains ADVANCE. The gallery retains its browser-level default. Every opened case stores its own mode in Drive metadata (workspaceMode); legacy cases adopt the gallery mode on their first open. Changes made in a case update its manifest without rewriting simulation files or invalidating results. Settings mode changes in the gallery affect only the gallery default.

In Basic, the case gallery plus button imports a Google Sheets link. The structural worksheet layout must match a recognized app template or legacy equipment headers. Compatible input is persisted as a new case, including parser diagnostics; the case opens even when input review is needed. Missing required nominal speed is preserved as null, not a fabricated operating rate. Review incomplete engineering inputs in the shared editable Basic table or in Standard/Advance. The normal model validation still applies. Marked exported templates use native equipment rates; legacy plant sheets use bottle-equivalent rates converted using a valid bottles-per-case value at the single case packer. The imported source rows are retained for review. New imports start with one eight-hour shift, one round, FAST, and the current engine; existing cases retain their saved duration and round settings.

The single workspace mounts the existing EquipmentTable component as one editable, resizable table in physical line order, with nonapplicable cells indicated by a dash. It shows the FAST simulation progress, a duration value/unit control and four featured baseline KPI cards (theoretical equipment efficiency, simulated efficiency, throughput, and production). The theoretical metric is 100 times the product of machine MTBF/(MTBF+MTTR), excluding conveyors. The duration toolbar retains saved run modes until an explicit edit, then sets fixed elapsed duration; editing inputs invalidates old results. The existing CAPEX explorer runs Zero, Medium and High sequentially. Its statistical analysis and validation remain internal; no DOE/ANOVA options are exposed in Basic. A single aggregate progress indicator reflects the current category and completed categories. Only current confirmed evaluation evidence yields scenario metrics. Exploratory or engineering-review results retain their qualification; unconfirmed/failed categories must not be presented as validated improvements. View improvements shows proposed parameter changes without applying them. Standard and Advance retain their original editor, new-case and analysis workflow.

Deploy all modified and new apps-script modules together. Verify a compatible and incompatible sheet, an incomplete draft, both language settings, all three modes, baseline rerun, all three optimization outcomes, and navigation after completion.

Table groups can be expanded or collapsed by clicking their heading without editing the model. The mixed table uses Material flow for both machine flow selectors and inferred conveyor transport units. Reliability has no per-machine enable column: all machines accept failure inputs, and conveyors cannot have own random failures or microstops in the app engines. General and Minor/Major pairs remain visible; in split mode the general pair is calculated from category frequencies, and in General mode the retained breakdown is disabled and not inferred. A blank pair or explicit 0/0 does not fabricate a failure rate. The run-level failure/category switches remain available outside the compact table. Recalculate older runs to apply the new conveyor policy.

## Compact group headers and machine model

A collapsed parameter group is a single text-fitted, resizable column with a header spanning all three rows (group, field and unit); expanded column widths and collapsed widths are independent. Actual group width animates horizontally and respects reduced-motion preferences. Category text uses a contrasting shade of the secondary color, and the toggle has no independent button background.

Basic hides Machine design and writes `machineDesignEnabled:false` into its run configuration. A common non-mutating input projection excludes internal capacity, occupancy model, residence time, recovery time and macrostop scrap from engine execution, model validation, input signatures and scenario planning. The discrete conveyor engine remains active, with no internal machine residence runtime in Basic; the original fields remain in the case for Standard and Advance. Older full-model results are not shown as Basic results and must be recalculated. Standard and Advance use the original full design behavior on a new run. This flag describes the calculation rather than merely the visible mode.

## Compact Settings

In Basic (MINIMAL), Settings is a single scrollable view rather than tabs. An open case shows General (name and complete-case export) followed by Appearance (language, theme, text size, primary and secondary colors and their existing reset controls). The existing hidden mode selector remains available with its five-M shortcut. In Case Gallery, the Drive workspace controls remain accessible alongside Appearance. Simulation, case layout, product-format and chart-series controls are not presented in Basic; their existing data and runtime controls are retained. Standard and Advance keep their tabbed Settings. The Basic export button and Basic gallery export download the complete captured draft or saved case JSON directly, with no export-selection or preview dialog, no filtering and no newly generated report annex. The existing export validation and capture of the current numerical/2D data are retained. Exporting does not save the case to Drive.
