# Zero CAPEX V6: OFAT → DOE → refinement (active)
Zero CAPEX V6 is available in Basic, Standard and Advance. Basic also supports Medium CAPEX buffer-extension searches. High CAPEX remains disabled. Ideal Line Benchmark is temporarily paused in the UI. The existing numerical motor and source simulation are unchanged. Historical exports are retained and must not be combined with the current method as new evidence.

## Fixed scope
Only installed conveyor controls are allowed: explicit Prime position or Lp reserve, Backup position, blocked/clear time delays, manual speed or automatic speed factor. Geometry length, machine rates, installed maxima, MTBF/MTTR, ramp profiles, and product profiles stay frozen. No packages, external hypotheses, fluid screening, or reliability target optimization. Dynamic controls, unadjustable inputs, format speed overrides and invalid/no-effect values are recorded as omitted. Speed hypotheses need installed drive-range verification; sensor changes need engineering approval. The existing model may still contain deterministic Prime/restart limitations.

## Procedure
1. Physical PRECISE diagnosis, 15 min (or compatible source horizon), one matched seed; compare original reliability with MTBF/MTTR events disabled. Diagnostic only.
2. Physical FAST OFAT, 15 min × 3 common seeds, up to 30 single-field alternatives. Breadth-first field coverage, then extra levels; priorities come from source loss diagnostics. Speed levels 80/90/110/120% of original, delay alternatives include pulse-duration margins, Prime reserve levels target distinct required packed queue counts, Backup moves remain within geometry. Values are checked against actual resolved geometry and no-op changes are omitted.
3. Up to three measured factors with distinct numeric levels; protect at least one interaction mechanism when available, not simply positive isolated gains. Full factorial, up to eight cells, matched FAST 30 min × 3 seeds and a new baseline; no hidden fixed changes. Existing blocked ANOVA and independent-seed contrast tests; incomplete factorials do not establish significance.
4. Retest up to two isolated alternatives; up to six midpoint/restoration refinement points on the same DOE basis. Choose among matched feasible results, requiring increased throughput without OEE regression and without increasing mean simulated overflow. Prefer zero-overflow outcomes; residual overflow is an engineering warning, not approved plant feasibility.
5. Up to three finalists; short physical seed block, then up to two on the one-hour FAST ranking horizon. PRECISE independent confirmation with planned six to twelve rounds (default cap six) and paired evidence; extend horizon for material rare failures or scheduled conditions. Use original source duration/resolution/seeds for final descriptive comparison, reusing compatible baseline. Overflow may not increase in any final acceptance gate. Engineering warnings remain.
6. Candidate budget up to 48 (OFAT/DOE/refinement), exploratory wall time 10 min; final ranking/confirmation and original verification outside that limit once a candidate has been selected. Cancel remains available. Longer scheduled studies can reach the time budget. Bounded local exploration, not an optimum guarantee.

## Minitab
Use 31_Zero_OFAT.csv (one seed per parameter level), DOE_ZERO_*.csv (one design per file, coded factor columns and Seed_Block), 30_DOE_seed_contrasts.csv and 32_Zero_refinement.csv; 23_CAPEX_paired_deltas.csv retains paired evidence. Compare only matching horizons, seeds and engine. Original verification is descriptive; no plant inference. Raw JSON retains invalid or omitted probes and other diagnostics. No RSM yet. Use Minitab to inspect effects/interactions and residuals after this new experiment is exported.

The V6 settings signature invalidates old evaluations as current confirmation. Physical simulation provenance is unchanged. The legacy automatic and three-tier UI tests describe a previous method and need review; the new Zero-specific tests cover the current contract.

## Deployment and execution guard
Basic searches Zero and Medium in sequence. A card search resets only that category. Medium evaluates complete accumulation-extension packages using the same physical simulator. High is disabled. Both card restart and evaluation check the engine signature `SCENARIO_SEARCH_ZERO_OFAT_V6`; incompatible or paused categories cannot enter the active queue. During Basic search the progress label shows the percentage and elapsed calculation time. Previous saved V5 results remain historical and are not current V6 evidence; the original numerical baseline is retained. After updating the Apps Script deployment, close/reload any open tabs (a previously loaded browser can continue executing its old client-side JavaScript until stopped/reloaded).
