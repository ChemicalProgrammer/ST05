# Minimal Basic workspace

Basic is the deployment default for fresh sessions. Its internal value is MINIMAL; Standard retains the old BASIC value, and Advance retains ADVANCE. Existing explicit browser mode preferences are preserved. The existing Settings mode selector still switches modes.

In Basic, the case gallery plus button imports a Google Sheets link. The structural worksheet layout must match a recognized app template or legacy equipment headers. Compatible input is persisted as a new case, including parser diagnostics; the case opens even when input review is needed. Missing required nominal speed is preserved as null, not a fabricated operating rate. Resolve incompatible/incomplete engineering inputs in Standard and reimport the corrected sheet before running. Marked exported templates use native equipment rates; legacy plant sheets use bottle-equivalent rates converted using a valid bottles-per-case value at the single case packer. The imported source rows are retained for review. New imports start with one eight-hour shift, one round, FAST, and the current engine; existing cases retain their saved duration and round settings.

The single workspace shows a read-only equipment/conveyor table in physical order, FAST simulation progress, three completed baseline KPI cards, and optimization. The existing CAPEX explorer runs Zero, Medium and High sequentially. Its statistical analysis and validation remain internal; no DOE/ANOVA options are exposed in Basic. A single aggregate progress indicator reflects the current category and completed categories. Only current confirmed evaluation evidence yields scenario metrics. Exploratory or engineering-review results retain their qualification; unconfirmed/failed categories must not be presented as validated improvements. View improvements shows proposed parameter changes without applying them. Standard and Advance retain their original editor, new-case and analysis workflow.

Deploy all modified and new apps-script modules together. Verify a compatible and incompatible sheet, an incomplete draft, both language settings, all three modes, baseline rerun, all three optimization outcomes, and navigation after completion.
